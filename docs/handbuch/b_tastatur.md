# Tastenkürzel

| Taste | Wirkung |
| :--- | :--- |
| **Strg + K** (macOS: **⌘ + K**) | Suchfeld auswählen und den Inhalt markieren |
| **/** | Suchfeld auswählen |
| **Esc** im Suchfeld | Suche leeren |
| **Esc** in einem Dialog | Dialog schließen |
| **↓** oder **j** | Nächste sichtbare Anforderung |
| **↑** oder **k** | Vorige sichtbare Anforderung |

Die Pfeiltasten wirken nicht, solange der Cursor in einem Eingabefeld steht.

Alle Schaltflächen sind auch mit der **Tabulatortaste** erreichbar und mit **Eingabe** oder **Leertaste** auszulösen. Im hohen Kontrast ist das jeweils ausgewählte Element besonders deutlich umrandet.
